CSS Week 2 – Lab Sheet

10 Practical Tasks to Master the Box Model, Typography, Colors, and Layout

1

Create a Basic Box Using Margin, Padding, and Border

In your stylesheet, create a selector called .box and assign:

  • A width
  • Padding on all sides
  • A visible border
  • A margin to separate it from other elements
2

Style a Title + Paragraph for Readability

Style h1 and p with:

  • Font sizing
  • Text alignment
  • Line height
  • Letter-spacing (optional)
3

Create a Colored Section

Make a class .section with a soft background color and contrasting text using color and background-color.

4

Round the Corners of a Box

Add border-radius to any element (for example, a card or image). Try different values: 6px, 12px, 50%.

5

Make a Horizontal Flex Layout

Create a container with class .flex-row containing 3 boxes.

  • Apply display: flex;
  • Use gap: to space the items
  • Use justify-content: to align them
6

Create a 3-Column Grid

Create a container with class .grid-3 and apply:

  • display: grid;
  • grid-template-columns: repeat(3, 1fr);
  • gap: for spacing
7

Experiment with List Styles

Style ul and ol using:

  • list-style-type (circle, square, decimal, none…)
  • padding-left to control indentation
8

Style a Link with Hover Effects

Style a and a:hover with:

  • color
  • text-decoration
  • Optional: Create a button-style link using padding, background, and border-radius.
9

Position an Element Using Relative + Absolute

Inside a .wrapper (set to position: relative;), place a small box at the top-right corner using:

  • position: absolute;
  • top: and right:
10

Create a Responsive Adjustment

Write a small media query: 

@media (max-width: 600px) {
    /* Change width, flex direction, or font size */
}
