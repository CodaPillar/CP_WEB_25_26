CSS Properties & HTML Elements

Each tab shows: which element we style, which CSS property we use, and a live example.

Text properties target: <p>

We style the text inside the paragraph element using color and font-size.

Live example

This is the actual paragraph being styled.

This paragraph is blue and slightly larger.

HTML + CSS pairing

Which element? <p> — Which properties? color, font-size.

<!-- HTML -->
<p>This paragraph is blue and slightly larger.</p>

<!-- CSS -->
p {
  color: darkblue;
  font-size: 20px;
}

Box properties target: <div class="card">

Here we style a <div> as a card: background, size, border, rounded corners.

Live example

The box below is our <div class="card">.

Card title
This is a simple content box.

HTML + CSS pairing

<!-- HTML -->
<div class="card">
  <strong>Card title</strong><br />
  This is a simple content box.
</div>

<!-- CSS -->
.card {
  width: 220px;
  height: 120px;
  background-color: #fdefc3;
  border: 2px solid #c59b42;
  border-radius: 10px;
  padding: 10px;
}

Spacing target: <div class="block">

Padding is space inside the element; margin is space outside the element.

Live example

Notice the distance between the border and the text (padding), and the distance between this box and other content (margin).

This block has padding and margin.
The text does not touch the border.

HTML + CSS pairing

<!-- HTML -->
<div class="block">
  This block has padding and margin.
</div>

<!-- CSS -->
.block {
  background-color: #f0f8ff;
  border: 1px solid #339;
  padding: 15px; /* inside space */
  margin: 15px;  /* outside space */
}

Text alignment target: <div class="box">

text-align affects how inline content (like text) is arranged inside the element.

Live example

The text in this box is centered horizontally.

This text is centered inside the box.

HTML + CSS pairing

<!-- HTML -->
<div class="box">
  This text is centered inside the box.
</div>

<!-- CSS -->
.box {
  border: 1px solid #666;
  padding: 10px;
  text-align: center;
}

Display target: <span class="item">

Here we use display: inline-block; so small boxes can sit next to each other.

Live example

Each label below is a styled <span> element.

Tag 1 Tag 2 Tag 3

HTML + CSS pairing

<!-- HTML -->
<span class="item">Tag 1</span>
<span class="item">Tag 2</span>
<span class="item">Tag 3</span>

<!-- CSS -->
.item {
  display: inline-block;
  background: #e0f7fa;
  border: 1px solid #0097a7;
  padding: 6px 10px;
  margin: 4px;
  border-radius: 6px;
}
