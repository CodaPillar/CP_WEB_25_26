CSS Week 2 — Classroom Cookbook

An ultra-practical companion to your Definitions Page. Each block is a tiny “recipe” to test in VS Code.

🍱 Box Model

1) Simple Card (margin + padding + border) 
/* CSS */
.card {
  width: 300px;
  padding: 20px;
  margin: 20px auto;
  background: #fafafa;
  border: 2px solid #ccc;
  border-radius: 8px;
}
HTML Test:
<div class="card">Hello, I’m a card!</div>
2) Center a Box Horizontally (classic margin auto) 
/* CSS */
.center-box {
  width: 200px;
  margin: 0 auto;
  padding: 1rem;
  background: #e9f0ff;
}
HTML Test:
<div class="center-box">Centered box</div>
3) Space Between Elements (margin-bottom) 
/* CSS */
.block {
  background: #eee;
  margin-bottom: 12px;
  padding: 10px;
}
HTML Test:
<div class="block">One</div>
<div class="block">Two</div>

🔤 Typography

4) Nice Title + Paragraph Text 
/* CSS */
h1 {
  font-size: 2rem;
  color: #333;
  margin-bottom: 0.5rem;
}

p {
  font-size: 1rem;
  line-height: 1.7;
  color: #555;
}
HTML Test:
<h1>Hello</h1>
<p>A paragraph to see spacing and readability.</p>
5) Center Text + Capitalize 
/* CSS */
.title {
  text-align: center;
  text-transform: capitalize;
  font-weight: bold;
}
HTML Test:
<h2 class="title">section header</h2>

📐 Layout (Flex & Grid)

6) Flex Center (horizontal + vertical) 
/* CSS */
.flex-center {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 200px;
  background: #f0f0f5;
}
HTML Test:
<div class="flex-center">Centered</div>
7) Two Columns with Flex 
/* CSS */
.columns {
  display: flex;
  gap: 1rem;
}

.col {
  flex: 1;
  padding: 1rem;
  background: #e8ffd9;
  border-radius: 6px;
}
HTML Test:
<div class="columns">
  <div class="col">Left</div>
  <div class="col">Right</div>
</div>
8) 3-Column Grid 
/* CSS */
.grid-3 {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1rem;
}

.grid-box {
  background: #ffe9e9;
  padding: 1rem;
  border-radius: 6px;
}
HTML Test:
<div class="grid-3">
  <div class="grid-box">1</div>
  <div class="grid-box">2</div>
  <div class="grid-box">3</div>
</div>

📌 Positioning

9) Absolute Box inside a Relative Container 
/* CSS */
.wrapper {
  position: relative;
  height: 200px;
  background: #eef0ff;
}

.absolute-box {
  position: absolute;
  top: 20px;
  right: 20px;
  background: #c7e0ff;
  padding: 0.5rem;
}
HTML Test:
<div class="wrapper">
  <div class="absolute-box">ABS</div>
</div>

🔗 Links

15) Remove Underline + Hover Underline 
/* CSS */
a {
  text-decoration: none;
  color: #0066cc;
}

a:hover {
  text-decoration: underline;
}
HTML Test:
<a href="#">Hover me</a>
16) Button-Style Link 
/* CSS */
.btn-link {
  display: inline-block;
  padding: 0.6rem 1rem;
  background: #4c6fff;
  color: white;
  border-radius: 6px;
  text-decoration: none;
}

.btn-link:hover {
  background: #2c48ce;
}
HTML Test:
<a href="#" class="btn-link">Click</a>
