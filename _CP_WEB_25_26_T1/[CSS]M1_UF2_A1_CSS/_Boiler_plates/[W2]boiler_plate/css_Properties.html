CSS Week 2 – Core Property Definitions

Quick reference for the main CSS properties you will see in class.

Use the tabs below to move between groups: Box Model, Typography, Layout, Positioning, Color, Borders, Lists, and Links.

Box Model layout

Every element is a box with content, padding, border, and margin. These properties control spacing and size.

margin
Space outside the element’s border, separating the element from others.
padding
Space inside the element’s border, pushing the content away from the edges.
border
The line around the element. Usually defined by border-width, border-style, and border-color together.
width
The horizontal size of the content area (not including margin, often not including padding/border unless box-sizing is changed).
height
The vertical size of the content area (same idea as width, for height).

Remember: the order for margins and padding in shorthand is always clockwise: top → right → bottom → left.

Typography text

These properties control how text looks: font, size, weight, spacing, and alignment.

font-family
The typeface used for the text (for example, Arial, Georgia, etc.).
font-size
How big the characters appear, usually in px, rem, or em.
font-weight
How bold the text is (for example normal, bold, or numeric values like 400, 700).
font-style
Whether text is normal or italic (for example normal, italic).
text-align
Horizontal alignment of text inside its container (left, center, right, justify).
text-decoration
Additional line on the text (for example underline, line-through, or none).
text-transform
Changes the case of letters (uppercase, lowercase, capitalize).
line-height
Vertical distance between lines of text; controls how “spaced out” lines feel.
letter-spacing
Extra space between individual letters.
word-spacing
Extra space between words.

Display & Layout structure

These properties control how elements are laid out on the page and how children are arranged.

display
Defines how an element behaves in the layout (block, inline, inline-block, flex, grid, etc.).
flex-direction
In a flex container, sets whether items flow in a row or column (for example row, column).
justify-content
In flex or grid, controls horizontal distribution of items along the main axis (flex-start, center, space-between, etc.).
align-items
In flex or grid, controls vertical alignment of items along the cross axis (flex-start, center, flex-end, etc.).
gap
Space between items in a flex or grid container (like a built-in margin between children).
flex-wrap
Controls whether flex items stay on one line or can wrap onto multiple lines.
grid-template-columns
Defines how many columns a grid has and how wide they are.
grid-template-rows
Defines how many rows a grid has and how tall they are.

Positioning stacking

These properties control how elements are positioned relative to their normal place or the viewport.

position
Chooses the positioning mode: static, relative, absolute, fixed, or sticky.
top, right, bottom, left
Offsets that move an element when it uses a non-static positioning mode. They define how far the element is from the respective edge.
z-index
Controls which elements appear “on top” when they overlap. A higher z-index means in front.

Color visual

These properties define the color of the text and background, and how transparent elements appear.

color
Text color of the element (can be defined with names, hex, rgb, hsl, etc.).
background-color
Background fill color of the element’s box.
opacity
Transparency of the whole element. 1 is fully visible, 0 is completely transparent.

Borders edges

Borders draw lines around elements and can be customized in thickness, style, color, and shape.

border-width
Thickness of the border line (for example 1px, 2px, etc.).
border-style
Visual style of the border ( solid, dashed, dotted, double, etc.).
border-color
Color of the border line.
border-radius
How rounded the corners of the box are. Higher values create more rounded corners.
outline
A line around the element, drawn outside the border. It does not affect layout and is often used for focus styles.

Lists bullets

List properties control the bullet or numbering style and the indentation.

list-style-type
Type of bullet or numbering for list items (for example disc, circle, decimal, none).
padding-left
Horizontal indentation inside the list, often used to control how far bullets and text sit from the edge.

Links anchors

These properties are commonly used to style anchors (<a> elements).

color
Text color of the link in its normal state (and also in visited/hover states if separately defined).
text-decoration
Controls the underline and other line styles on links (for example underline or none).
