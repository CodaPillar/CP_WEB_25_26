Model client servidor

Presetacio

En el modelo cliente-servidor, el navegador del usuario (cliente) envía peticiones al servidor, que procesa la información y devuelve una respuesta. En el lado cliente se ejecutan lenguajes como JavaScript para crear interactividad inmediata, validar formularios y mejorar la experiencia sin recargar la página. En el lado servidor se ejecutan lenguajes como PHP o Python, que gestionan la lógica y acceden a bases de datos como MySQL u Oracle. Este flujo permite que cliente y servidor trabajen juntos para mostrar información actualizada y ofrecer páginas más rápidas y funcionales.
