Model cliente-servidor

Material del curso:

Slideshow - unidad curso

En el modelo cliente-servidor, el navegador del usuario (cliente) envía peticiones al servidor, que procesa la información y devuelve una respuesta.

  1. En el lado cliente se ejecutan lenguajes como JavaScript para crear interactividad inmediata, validar formularios y mejorar la experiencia sin recargar la página.
  2. En el lado servidor se ejecutan lenguajes como PHP o Python, que gestionan la lógica y acceden a bases de datos como MySQL u Oracle. Este flujo permite que cliente y servidor trabajen juntos para mostrar información actualizada y ofrecer páginas más rápidas y funcionales.

Consorcio World Wide Web (W3C)

El Consorcio World Wide Web (W3C) es una organización internacional de interés público sin fines de lucro donde las organizaciones miembros, un equipo a tiempo completo y el público en general colaboran para desarrollar estándares web. Fundado por el inventor de la web, Tim Berners-Lee.

W3Schools - recursos didacticos

W3Schools es un sitio web para aprender tecnologías web en línea. Contiene tutoriales de HTML, CSS, JavaScript, SQL, PHP, XML y otras tecnologías.Fue lanzado en 1999 por la empresa noruega Refsnes Data, y su nombre proviene de la World Wide Web. W3Schools presenta cientos de ejemplos de código. Tiene un editor de texto en línea llamado TryIt Editor, y los lectores pueden editar ejemplos y ejecutar el código en un entorno de pruebas.

Visual Studio Code - editor the texto

Visual code studio downloads
Visual Code Studio es un editor de texto multiplataforma ampliamente utilizado en el sector para el desarrollo de aplicaciones diversas, incluido el diseño y la programación web. Al ser un editor open source, permite su implementación mediante múltiples librerías y plugins. El programa puede configurarse por completo, lo que añade una capa de funcionalidad altamente personalizada.
