## 🔵 PART 1 — Partition Plan (Dual Boot + Shared Storage)

```
DISK LAYOUT (after Lenovo arrives)

[Windows 11] — NTFS — 150–200 GB
[L i n u x ] — ext4 — 60–100 GB

Shared Partition path names:
```

- macOS can read instantly

## 🟣 PART 3 — SSH + SFTP Lab (Universal Remote Access)

Enable OpenSSH on:

- Debian VM
- Windows (built-in OpenSSH server)
- Linux dual boot

**Generate keys (on Mac first):**

```
ssh-keygen -t ed25519 -C "caterpillar"
```

**Copy keys:**

```
ssh-copy-id user@linux-ip
ssh-copy-id user@windows-ip
```

**Access machines from each other:**

```
ssh user@linux-ip
ssh user@windows-ip
ssh user@debian-vm
```

**File transfer:**

```
sftp user@linux-ip
pscp file.txt user@windows-ip:
rsync -avP Notes/ user@linux-ip:Notes/
```

This makes ALL systems behave like **one network organism**.
