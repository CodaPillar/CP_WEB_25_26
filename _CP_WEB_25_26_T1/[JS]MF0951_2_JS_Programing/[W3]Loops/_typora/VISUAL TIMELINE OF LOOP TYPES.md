## 🕒 **POINT 4️⃣ — VISUAL TIMELINE OF LOOP TYPES**

**“How loops evolve in Weeks 3–4 of a beginner course”**

This is written as a **clear didactic poster** you can paste into Typora.

------

### 🎓 **TIMELINE: HOW STUDENTS LEARN LOOPS (WEEK 3 → WEEK 4)**

```markdown
WEEK 3 — Introduction Stage
───────────────────────────
• Counting loops (1→10)
• Backwards loops (10→1)
• Step-by-step loops (x += 2)
• Accumulators (sum += i)
• Understanding “start → condition → update”
• No functions, no DOM — console only
• Mental model: “repeat the same instruction many times”
WEEK 3.5 — Differentiation Stage
────────────────────────────────
• Compare FOR vs WHILE
• WHEN to use which:
      - for → fixed number of repetitions
      - while → continue until something changes
• Small logical errors:
      - forgetting i++
      - wrong boundaries
      - using < instead of <=
• First exposure to do…while (guaranteed one run)
WEEK 4 — Application Stage
───────────────────────────
• Word problems:
      - bank counting problems
      - disco entry checks
      - cafeteria stock examples
      - “affordance” problems (Does the user have enough?)
• Pattern building:
      - extract multiples (2, 5, 10…)
      - accumulate results into a total
      - tracking time or steps
• Loop + condition interaction
      - “only print values that satisfy …”
      - “stop when condition breaks”
• Still no functions — procedural top-to-bottom logic
WEEK 4.5 — Pre-Functions Stage
──────────────────────────────
• The idea that loops can become reusable later
• Breaking problems into:
      1) variables
      2) loop
      3) internal logic
• Preparing for “loop inside function” (future)
• Confidence with operators inside loops
```

------

## 🧭 **Mini-summary for students**

> **A beginner loop is a simple repetition engine.
>  First you learn the engine.
>  Then you learn to place small decisions inside the engine.
>  Only later you learn to wrap the engine into a function.**

This sequence stabilizes the learner — especially someone coming from conditionals — and avoids cognitive overload.
