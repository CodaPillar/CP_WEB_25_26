2. HTML

What is HTML?

  • HTML stands for Hyper Text Markup Language
  • HTML is the standard markup language for creating Web pages
  • HTML describes the structure of a Web page
  • HTML consists of a series of elements
  • HTML elements tell the browser how to display the content
  • HTML elements label pieces of content such as "this is a heading", "this is a paragraph", "this is a link", etc.

Example


<!DOCTYPE html>
<html>
    <head>
        <title>Page Title</title>
    </head>
    <body>
        <h1>My First Heading</h1>
        <p>My first paragraph.</p>
    </body>
</html>

Example Explained

  • The <!DOCTYPE html> declaration defines that this document is an HTML5 document
  • The <html> element is the root element of an HTML page
  • The <head> element contains meta information about the HTML page
  • The <title> element specifies a title for the HTML page (which is shown in the browser's title bar or in the page's tab)
  • The <body> element defines the document's body, and is a container for all the visible contents, such as headings, paragraphs, images, hyperlinks, tables, lists, etc.
  • The <h1> element defines a large heading
  • The <p> element defines a paragraph

2.1. HTML Elements

An HTML element tells the browser how to display the document. It is defined by a start tag, some content, and an end tag:

<tagname> Content goes here... </tagname>

Note: Tagnames are not case sensitive. The HTML standard does not require lowercase tags, but W3C recommends lowercase in HTML

The HTML element is everything from the start tag to the end tag:

<h1>My First Heading</h1>
<p>My first paragraph.</p>
Start tag Element content End tag
<h1> My First Heading </h1>
<p> My first paragraph. </p>
<br> none none

Note: Some HTML elements have no content (like the <br> element). These elements are called empty elements. Empty elements do not have an end tag!



Nested HTML Elements

HTML elements can be nested (this means that elements can contain other elements). So, all HTML documents consist of nested HTML elements.

The example contains four HTML elements (<html>, <body>, <h1> and <p>):

  • The <html> element is the root element and it defines the whole HTML document.
  • It has a start tag <html> and an end tag </html>.
  • Then, inside the <html> element there is a <body> element:
    • The <body> element defines the document's body.
    • It has a start tag <body> and an end tag </body>.
    • Then, inside the <body> element there are two other elements: <h1> and <p>.

Some HTML elements will display correctly, even if you forget the end tag, but never skip the end tag.

2.2. Web Browsers

The purpose of a web browser (Chrome, Edge, Firefox, Safari) is to read HTML documents and display them correctly.

A browser does not display the HTML tags, but uses them to determine how to display the document:


View HTML Source Code:

Right-click in an HTML page and select "View Page Source" (in Chrome) or "View Source" (in Edge), or similar in other browsers. This will open a window containing the HTML source code of the page.

Inspect an HTML Element:

Right-click on an element (or a blank area), and choose "Inspect" or "Inspect Element" to see what elements are made up of (you will see both the HTML and the CSS). You can also edit the HTML or CSS on-the-fly in the Elements or Styles panel that opens.


2.3. HTML Page Structure

Below is a visualization of an HTML page structure:

<html>
<head>
<title>Page title</title>
</head>
<body>
<h1>This is a heading</h1>
<p>This is a paragraph.</p>
<p>This is another paragraph.</p>
</body>
</html>

Note: The content inside the <body> section (the white area above) will be displayed in a browser. The content inside the <title> element will be shown in the browser's title bar or in the page's tab.

2.4. HTML Attributes

  • All HTML elements can have attributes
  • Attributes provide additional information about elements
  • Attributes are always specified in the start tag
  • Attributes usually come in name/value pairs like: name="value"
  • Double quotes around attribute values are the most common in HTML, but single quotes can also be used depending of the situation.
Example:

<body bgcolor="blue">



3. Basic tags

HTML Paragraphs


HTML paragraphs are defined with the <p> tag:
Example
<p>This is a paragraph.</p>
<p>This is another paragraph.</p>

You cannot be sure how HTML will be displayed. Large or small screens, and resized windows will create different results. With HTML, you cannot change the display by adding extra spaces or extra lines in your HTML code.

The browser will automatically remove any extra spaces and lines when the page is displayed:

Example
<p>
This paragraph
contains a lot of lines
in the source code,
but the browser
ignores it.
</p>

<p>
This paragraph
contains         a lot of spaces
in the source         code,
but the        browser
ignores it.
</p>


HTML Headings


HTML headings are defined with the <h1> to <h6> tags.

<h1> defines the most important heading. <h6> defines the least important heading.

Example
<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

HTML Comment Tag

You can add comments to your HTML source by using the following syntax:

<!-- Write your comments here -->

Notice that there is an exclamation point (!) in the start tag, but not in the end tag.

Example: 

<!-- This is a comment -->
<p>This is a paragraph.</p>
<!-- Remember to add more information here -->

Other tags

  • The <br> tag defines a line break.
  • The <hr> tag draws a horizontal rule

4. Text formatting

Formatting elements were designed to display special types of text:

  • <b> - Bold text
  • <strong> - Important text
  • <i> - Italic text
  • <em> - Emphasized text
  • <mark> - Marked text
  • <small> - Smaller text
  • <del> - Deleted text
  • <ins> - Inserted text
  • <sub> - Subscript text
  • <sup> - Superscript text
The HTML <strong> element defines text with strong importance. The content inside is typically displayed in bold.
The HTML <em> element defines emphasized text. The content inside is typically displayed in italic.

7. Images

The HTML <img> tag is used to embed an image in a web page.

Images are not technically inserted into a web page; images are linked to web pages. The <img> tag creates a holding space for the referenced image.

The <img> tag is empty, it contains attributes only, and does not have a closing tag.

The <img> tag has two required attributes:

  • src - Specifies the path to the image
  • alt - Specifies an alternate text for the image
Example:
<img src="img_chania.jpg" alt="Flowers in Chania">
Alternatively, you can use the width and height attributes:
<img src="img_girl.jpg" alt="Girl in a jacket" width="500" height="600">
If you have your images in a sub-folder, you must include the folder name in the src attribute:
<img src="/images/html5.gif" alt="HTML5 Icon">
To point to an image on another server, you must specify an absolute (full) URL in the src attribute:
<img src="https://www.w3schools.com/images/w3schools_green.jpg" alt="W3Schools.com">

8. Entities

Some characters are reserved in HTML. If you use the less than (<) or greater than (>) signs in your text, the browser might mix them with tags. Character entities are used to display reserved characters in HTML.

A character entity looks like this:

&entity_name;

OR

&#entity_number;

To display a less than sign (<) we must write: &lt; or &#60;

Advantage of using an entity name: An entity name is easy to remember.
Disadvantage of using an entity name: Browsers may not support all entity names, but the support for entity numbers is good.

9. Atribut align

The purpose of the HTML align attribute is to specify the alignment of data and the justification of text in a cell of a table.

Supported Tags:

  • <applet>
  • <caption>
  • <col>
  • <colgroup>
  • <hr>
  • <iframe>
  • <img>
  • <p>
  • <table>
  • <tbody>
  • <td>
  • <tfoot>
  • <th>
  • <thead>
  • <tr>

Syntax:

<element_name align="left | right | center | justify">

Attribute Values:

  • left: It sets the text left-align.
  • right: It sets the text right-align.
  • center: It sets the text center-align.
  • justify: It stretch the text of paragraph to set the width of all lines equal.
Examples:
<p align="left">Left align content</p>
<p align="center">center align content</p>
<p align="right">Right align content</p>

10. Links

Text or graphic area that takes us to another document or to another position within the same document. The linked document does not need to be "nearby" (Internet).

We will use the A (anchor) tag.

<A HREF="address">Link text</A>

The address must be in the URL (Uniform Resource Locator) format:

service://machine:port/path/file#section

Example:

http://www.xtec.cat

Link types

  • Absolute links: specify a unique document on the Internet.
service://machine:port/route/file
  • Relative links: specify a document positioned relative to the current document.
path/file
  • Internal links: specify a part of the document (anchors).
file#section

Services

  • http
  • https: http service with built-in security (encryption, etc.).
  • ftp
  • mailto
  • news
  • telnet

Relative links

They specify a document positioned relative to the current document.

  • Different folders (directories) are separated with /
  • To indicate an upper folder, use ..

Examples:

<A HREF="courses/index.html">Link</A>
<A HREF="../index.html">Link</A>

Internal links

With internal links it is possible to access different positions in a document. The position you want to access must be specified:

<A NAME="some_name">

To link from the same document:

<A HREF="#some_name">Section Access</A>

To link to it from another document:

<A HREF="file.html#some_name">Section access</A>

11. Lists

Lists are a resource we use to make an enumeration. There are three types of list:

  • ordered lists.
  • unordered lists.
  • definition lists.

Although initially the ordered <ol> and disordered <ul> lists are very differentiated, from CSS we can modify the aesthetics and get the same look.

Ordered lists

Ordered lists are the lists in which we need the items to be numbered. To mark the beginning and end of the list we use the tag <ol> (ordered list) and to mark each item in the list we use the tag <li> (list item).

Imagine we are making a recipe and want to list the steps we need to follow. The code would be as follows:

<h2> Preparation </h2>
<ol>
    <li> Beat the eggs </li>
    <li> Heat the oil in a frying pan </li>
    <li> Throw the beaten eggs in the pan </li>
    <li> Wrap the omelette </li>
</ol>

Unordered lists

Unordered lists are lists in which we do not need items to be numbered, that is, the order of the enumeration is not required. To mark the beginning and end of the list we use the tag <ul> (unordered list) and to mark each item in the list we use the tag <li> (list item).

If, for example, we want to list all the ingredients needed to make a French tortilla, we code it as follows:

<h2> Ingredients </h2>
<ul>
    <li> Eggs </li>
    <li> Sal </li>
    <li> Oil </li>
</ul>

Definition lists


Definition lists are characterized by being an enumeration of definitions of terms. Therefore, the items in the definition lists are made up of two elements: the term and the definition of that term. To mark the beginning and end of the list we use the tag <dl> (definition list); the term <dt> (definition term) is used for each of the terms, and the <dd> (definition description) tag is used for each of the definitions.

For example, if we want to define the terms HTML, CSS and JavaScript, we can use this type of list.

<dl>
    <dt> HTML </dt>
    <dd> Markup language designed to structure text. </dd>
    <dt> CSS </dt>
    <dd> Language created to define the appearance of documents. </dd>
    <dt> JavaScript </dt>
    <dd> Interpreted programming language. </dd>
</dl>

Nested lists

If we want to make complex lists, that is, insert lists into other lists, we can do the same. All we have to do is open and close the tags correctly: if we want to encapsulate a list, either numbered or unnumbered. This list must be in an item (<li>) in the parent list.
As an example, we can think of steps for making a web design of the client environment:

<h1> Phases in web design. </h1>

    </ol>

    <ul>
        <li> Choice of languages. </li>
        <li> Testing in different browsers. </li>
        <li> Tests at different resolutions. </li>
    </ul>
    <li> Delivery of templates to the customer. </li>
</ol>

Other

12. Paths

  • Files are storage units from the user's point of view.
    • Generally, files are identified by their name and their extension, although sometimes the extension is not necessary, or simply it hides.
  • Folders are containers that can hold more than one at a time  folders or files.
  • The graphical way to represent folders and subfolders of a disk is the tree structure, as it represents a tree inverted, or if you want, the part of the roots.
    • The idea is that each folder can contain folders within it inside we call them subfolders), and so recursively.

Folder structure

An example of folder structure in Windows could be:


Paths

  • The top node of the folder tree structure is called the root. In Windows it is the name of a drive (C:, D:, etc.). In Linux operating systems the root is /.
    • The path from the root to a specific folder or file is called absolute path. Example: C:\Windows, C:\Users\Mary\Work, ...
    • The path from where you are to a particular folder or file is called relative path. We must take into account that .. indicates the upper folder (immediately above). Example (we are in the Users folder): Maria\Work, ..\Windows, ...

Web pages

In web pages design the relative path is always used, since it allows to move an entire website without any problem. It should be noted that some programs that allow you to create web pages, depending on the action taken, use the absolute path. You need to correct it by hand.

13. Tables

HTML tables allow web developers to arrange data into rows and columns. A table in HTML consists of table cells inside rows and columns.

Example:

<table>
  <tr>
    <td>Emil</td>
    <td>Tobias</td>
    <td>Linus</td>
  </tr>
</table>
Each table cell is defined by a <td> and a </td> tag. td stands for table data. Everything between <td> and </td> are the content of the table cell.

A table cell can contain all sorts of HTML elements: text, images, lists, links, other tables, etc.

Each table row starts with a <tr> and ends with a </tr> tag. tr stands for table row. You can have as many rows as you like in a table; just make sure that the number of cells are the same in each row.

Table Headers

Sometimes you want your cells to be table header cells. In those cases use the <th> tag instead of the <td> tag:

<table>
  <tr>
    <th>Name</th>
    <th>Surname</th>
    <th>Alias</th>
  </tr>
  <tr>
    <td>Emil</td>
    <td>Tobias</td>
    <td>Linus</td>
  </tr>
</table>
th stands for table header.

To use the first column as table headers, define the first cell in each row as a <th> element:

<table>
  <tr>
    <th>Firstname</th>
    <td>Jill</td>
    <td>Eve</td>
  </tr>
  <tr>
    <th>Lastname</th>
    <td>Smith</td>
    <td>Jackson</td>
  </tr>
  <tr>
    <th>Age</th>
    <td>94</td>
    <td>50</td>
  </tr>
</table>

Attributes

Some attributes:

  • border
  • width, height
  • bgcolor
  • align: left, center, right
  • valign: top, middle, bottom
Example:

<table width=50% bgcolor="yellow" border=1>
  <caption align="bottom">Example of a table</caption>
  <tr bgcolor="green">
    <th>Name</th>
    <th>Surname</th>
    <th>Alias</th>
  </tr>
  <tr>
    <td bgcolor="red"><font color="white"><i>Emil</i></font></td>
    <td width=500 height=50 align="center" valign="top">Tobias</td>
    <td>Linus</td>
  </tr>
</table>

Padding & Spacing

HTML tables can adjust the padding inside the cells, and also the space between the cells.

Example:

<table cellpadding=10 cellspacing=5>

Colspan & Rowspan

HTML tables can have cells that span over multiple rows and/or columns.



To make a cell span over multiple columns, use the colspan attribute:

<table>
  <tr>
    <th colspan="2">Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Jill</td>
    <td>Smith</td>
    <td>43</td>
  </tr>
  <tr>
    <td>Eve</td>
    <td>Jackson</td>
    <td>57</td>
  </tr>
</table>

To make a cell span over multiple rows, use the rowspan attribute:

<table>
  <tr>
    <th>Name</th>
    <td>Jill</td>
  </tr>
  <tr>
    <th rowspan="2">Phone</th>
    <td>555-1234</td>
  </tr>
  <tr>
    <td>555-8745</td>
</tr>
</table>

14. Frames

Definition

  • Documents without content.
  • Function of splitting the screen into multiple areas.
  • The content of a frame is an HTML file.
  • Frames do not have BODY, they have the FRAMESET tag instead.

Structure

<html>
    <frameset ...>
        More specifications about frames
    </frameset>
    <noframes>
        <P>This page can only be viewed if the browser supports frames.</P> 
    </noframes>
</html>

Size

The size of the frame can be indicated with:
  • Percentage
  • Absolute value
  • About the rest
Example:
<FRAMESET COLS="10%,*,200,2*">
<FRAMESET ROWS="10%,*,200,2*">

Nesting

<FRAMESET COLS="20%,80%">
    <FRAME NAME="index" SRC="index.html">   
    <FRAMESET ROWS="*,80">     
        <FRAME NAME="menu" SRC="me.html">     
        <FRAME NAME="exemple" SRC="ex.html">   
    </FRAMESET> 
</FRAMESET>

Attributes

  • name
  • src
  • scrolling="yes" | "no" | "auto": controls the appearance of scrollbars.
  • noresize: prevents resizing frames.
  • frameborder=number: indicates the size of the border.

Links

The hyperlinks of each of the frames can be a link for the same frame, the entire document or in another frame. 

<a href=address target="name">
where name is the name given to the corresponding frame.

Special redirections:
  • _blank: exit the frameset and go to a new window.
  • _self: loads the new page in the same frameset (default).
  • _relative: load the new page in the immediate top frameset.
  • _top: loads the new page in the absolute top frameset.

Example

<FRAMESET COLS="20%,80%">   
    <FRAME NAME="index" SRC="index.html">   
    <FRAMESET ROWS="*,80">     
        <FRAME NAME="menu" SRC="me.html">     
        <FRAME NAME="example" SRC="ex.html">   
    </FRAMESET>
</FRAMESET>
